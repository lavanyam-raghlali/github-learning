# Example: Event Planning Guide
# Community Cleanup Event

## Objective

Organize a neighborhood cleanup to improve the local environment.

## Schedule

| Time | Activity |
|------|----------|
| 9:00 AM | Registration |
| 9:30 AM | Safety briefing |
| 10:00 AM | Cleanup begins |
| 12:00 PM | Refreshments |

## Volunteer Checklist

- [ ] Register participants
- [ ] Distribute gloves and bags
- [ ] Assign cleanup zones
- [ ] Collect waste

## Emergency Contact

Call the event coordinator if assistance is needed.
